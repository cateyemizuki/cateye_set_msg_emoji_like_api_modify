# 添加或修改表情映射

编辑 `emoji_map/emoji_reaction_custom.json`。使用实际的数字表情 ID，填写想让 Bot 看到的名称、描述和情绪标签。

下面以 76 为例，给现有表情增加检索词。

```json
{
  "76": {
    "name": "赞",
    "description": "点赞，表达赞同或认可。",
    "emotion_tags": ["点赞", "赞同", "认可", "鼓励"]
  }
}
```

重新加载插件或重启 MaiBot 后，用 `emoji_like` 搜索对应的情绪词。工具会返回匹配结果的 ID 与描述，传回其中一个 ID 即可贴表情。候选超过上限时会随机抽取，可以搜索更具体的描述来缩小范围。

若要把自定义内容放在插件目录之外，可将环境变量 `QQ_EMOJI_EXTRA` 指向自己的 JSON 文件，再重启 MaiBot。环境变量指向的映射优先于插件内的自定义表。[加载顺序与兼容格式](README.md#json-formats)

如果查得到却贴不出，检查目标是否为真实 QQ 消息，以及该表情是否支持贴到当前类型的消息。映射用于查找表情，实际贴表情由 QQ 适配器处理。
